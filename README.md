## Jest to Vitest migration skill

- Location: `./skills/migrate-jest-to-vitest`

The generic extraction from the migration skill used to transform the monorepo of 830 workspaces, 4,5 million LoC, 7300
Jest test files, and ~74000 Jest tests. Dropped repo-specific parts and generalized the patterns that can be useful for
everyone doing the similar migrations at scale.
